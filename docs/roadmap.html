Kiến trúc

FastAPI API, React + TypeScript UI, SQLite metadata, local image volume. OpenAI và endpoint OpenAI-compatible qua provider adapter.

  • Auth: email/mật khẩu và session cookie an toàn.
  • Provider: admin cấu hình provider/model/credential qua environment.
  • Model routing: LangChain Core chọn alias phía server; LangSmith ghi trace metadata khi bật.
  • Ownership: mọi ảnh và file chỉ truy cập bởi chủ sở hữu.

Người dùng chỉ chọn số lượng 1–6; không chọn provider, model hoặc thông số sinh ảnh khác. App không báo thành công nếu provider hoặc lưu file thất bại.

Đăng ký/đăng nhập, SQLite, local volume, thư viện theo chủ sở hữu và tải ảnh.

2. Generation, edit và variation — Hoàn thành offline

Provider interface và adapter OpenAI-compatible đã được kiểm tra bằng fake provider. LangChain model routing và LangSmith trace cục bộ đã được kiểm tra. OpenAI API, self-hosted endpoint và LangSmith remote chưa được xác nhận.

3. Giao diện và kiểm chứng — Hoàn thành offline
